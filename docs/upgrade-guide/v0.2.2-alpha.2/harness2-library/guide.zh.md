# Harness² 经验库版本 2

[English](guide.md) | 中文

## 变更

原生递归 Harness² 服务使用 `harness2` 存储领域版本 2。已有版本 1 文本预览存储会因版本不匹配被拒绝；服务不会转换旧数据。版本 2 保存候选树、已接受任务经验、运行指纹和阶段检查点。此变化影响启用了实验性版本 1 服务的部署，不影响普通 Session 历史或未启用 Harness² 的配置组合。

## 迁移

1. 升级前保留现有存储和可运行的旧应用副本。不要删除、改版本标签或编辑版本 1 记录来绕过版本检查。
2. 如果需要现有经验库，在有明确迁移方案前，继续使用旧服务及其原始存储。此变更不提供原地迁移。
3. 如需独立评估新服务，通过[存储提供方](../../../../packages/storage/storage-domain/README.zh.md)配置独立部署存储位置。保持旧位置完整；新运行不会自动导入旧经验。
4. 确认新服务打开全新的 `harness2` 领域并完成预览。对需要的新经验另行评审和批准。版本不匹配错误表示仍选中了旧存储，不表示转换成功。
